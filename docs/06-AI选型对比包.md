## 0. 先花 2 分钟：测它到底能不能"看图"（✅ 已测过，保留作复测用）

这一步**必须先做**。"哪家哪个模型收图"我不能凭记忆给结论，只能当场验证；如果它看不了图，后面的图像辨识和碎片读图两组都不用跑了。

新建一个对话，把 `design/img/q-image.jpg` 传进去，然后发这一句：

```
请告诉我这张画里画了什么，尽可能具体：画了什么人物、手里拿着什么、
光线从哪边来、背景是什么颜色。
```

**怎么判读**

| 它的回答 | 结论 |
| --- | --- |
| 说出了"一位女子、手里拿着一只水壶 / 奶壶、站在窗边、光从左来"这类**具体内容** | **能看图**，继续第 1 步 |

## 1. 系统提示词（每个新对话**先贴这段**，再往下）

```
你是我的美术史复盘出题助手。我的背景：油画专业硕士在读，美术史功底远高于普通爱好者。

请严格遵守以下规则：
1. 难度对标央美 / 国美 / 清美等院校的美术史考研真题，不要出普及读物水平的题。
   严禁出现"南北宗论""文艺复兴三杰是谁"这一类通识送分题。
2. 每题必须给：题干、题型、难度档（基础 / 进阶 / 挑战）、参考答案、一段解析。
   解析里要同时说清两件事：这道题的考点是什么、最容易错在哪。
3. 事实必须准确。年代、作者、流派、作品名一旦不确定，宁可不写也不要编；
   如果你对某个归属有疑问，直接在解析里标注"存疑"，不要含糊过去。
4. 不要写客套话，不要复述我的要求，不要问我还有没有别的问题，直接从第一题开始。
```

## 2. 出题测试（纯文字，复制整段发过去）

```
请按下面配额出 6 道题，中外美术史混合，不按时间线排序：

- 名词解释 2 道：取"术语 + 史学理论"这个量级（例如"有意味的形式""图像证史"），不要通识名词。
- 简答 1 道：要有可展开的史学争议点。
- 开放论述 1 道：偏"创作实践"方向（笔触该不该被看见、完成感从哪来、写生与重构的关系等），
  要有争议点，不给标准答案，只给参考思路。
- 客观题 2 道：用于巩固基础，但要有区分度。

每题按这个格式输出：

【第N题】题型 | 难度档
题干：
答案：
解析：（考点 + 最容易错在哪）
```

**要记的**：有没有冒出送分题？把送分题的题面抄一句下来。

传的还是 `design/img/q-image.jpg`。

```
我上传了一张油画。请做两件事：

一、先判断这幅画：作者、创作年代、所属流派、你的判断依据。
```

## 5. 打分（每项 1～5 分）

| 维度 | 5 分 | 3 分 | 1 分 |
| --- | --- | --- | --- |
| **史实准确**（一票否决） | 年代 / 作者 / 流派 / 作品名全对 | 有 1 处小瑕疵，但不影响判断 | **有归属或年代错误 → 这家直接淘汰** |
| **难度** | 有明显区分度，像考研题 | 部分题偏浅 | 出现"南北宗论"级送分题 |
| **解析水准** | 有争议点、有史学视角，读完有收获 | 讲清了考点，但平 | 百科式复述，等于没解析 |
| **读图能力** | 能说出作者 / 年代 / 题材 / 风格特征 | 能说画面内容，说不清作者年代 | 看不出图，或硬猜还猜错 |

> **史实准确是唯一的一票否决项**。其余三项可以容忍，这一项不能——它直接决定你还信不信这个产品。

## 7. 怎么算"通过"

- **第 0 步能看图** → 通过，可以开工。
- **第 0 步看不了图** → 先确认用的是不是 `GLM-5.3-Flash`（Model Code `glm-5.3-flash`），别错选了纯文本的 `GLM-5.3` 或 `GLM-4.7-Flash`；确认无误仍看不了，就得回到 02 第十节那条硬约束上重新讨论。
- **史实准确这一项不过** → 不管其他项多好都不能用，得换模型重测。

**这次自测还会顺带回答一个问题**：图像辨识题的"作者 / 年代"，要不要改成**直接取博物馆元数据**（Met 接口里就有 `artistDisplayName`、`objectDate`），AI 只写风格依据和干扰项。
——如果它把维米尔认错或说不确定，那这条就该落地：把幻觉风险最大的那一环交给权威数据，不交给 AI。
