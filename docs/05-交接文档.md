## 4. 怎么打开设计稿

- 直接用浏览器打开 `design/今日页-视觉方向对比.html`（纯静态，无需起服务）。
- **主界面**：鼠标左右移动 → 整排卡片跟着平移；点卡片 → 第一下就地展开预览，第二下进内容页；按**回车**直接落到今日页。
- 顶部条可切四套皮对比（A · 美术馆标签 / **B · 夜馆** / C · 纸本 / D · 夜馆·编辑式），打开默认就是 B。
- 今日页里可点图放大；「有 / 无动效」开关用于对比动效。
- **进去之后**：左上角常驻「← 返回主界面」（二级页都能回来）；右下角那颗圆是**碎片入口**，点一下它横向展开说"v0.2 再做"；**桌面推送通知**在主界面停留约 1 秒后从右下角弹出（在圆钮上方），点它直接进今日页。

## 6. 已知的坑（2026-10-08 实测，别再踩）

| 坑 | 现象 | 结论 |
| --- | --- | --- |
| 内置生图接口 | `trae-api-cn.../text_to_image` 只返回灰底占位图，不同 prompt 的返回值 MD5 完全一致，等 20 秒再取仍是它 | **不要拿它当图源**，必须用博物馆直链或本地图 |
| Met 搜索接口 | `/public/collection/v1/search` **已于 2026-10-01 下线**，返回一段提示 JSON（不是 `objectIDs`），看起来像"搜不到" | 改用 `/public/collection/v1.1/search`（带 `offset` / `limit` 分页） |
| Wikipedia | `en.wikipedia.org` 在本机超时不可达（境内网络） | 不要用它当图源 |
| Shell 输出的 CLIXML | 每条命令都带一段"profile 脚本被禁用"的报错 | 是环境噪声，命令本身正常执行，**忽略** |
| better-sqlite3 装不上 | `npm install` 报 node-gyp `Could not find any Visual Studio installation`，或 prebuild-install 报 `Request timed out`；npm 11 还会提示 install script 未放行 | **不是缺编译工具**，是从 github.com releases 下预编译包超时（境内网络）。本机 Node 是 v24（ABI 137），npmmirror 上有对应预编译包；项目根 `.npmrc` 已配镜像，若仍失败执行 `npm rebuild better-sqlite3`。**不要为此装 VS Build Tools** |
| Node 不在 PATH | 终端敲 `node` / `npm` 报"不是内部或外部命令" | 本机 Node 在 `E:\New Folder\nodejs`，已加进用户 PATH；**已打开的终端要重开才生效** |

**可直接用的取图链路**：`/public/collection/v1.1/search` → `/public/collection/v1/objects/{id}` 的 `primaryImageSmall` → 下载到本机。
`collectionapi.metmuseum.org`、`images.metmuseum.org`、`api.artic.edu` 均可达；`www.artic.edu` 返回 403。

## 7. 硬约束速查

**编码**

1. AI 生成的内容**必须落库**，不许只在内存里（否则刷新就重复花钱）。
2. 密钥只走 `.env`，不进版本库，文档与代码里不得出现。
3. 图片**一律本地缓存**，禁止外链直显。
4. 日期按本地时区（Asia/Shanghai）判跨天。
5. 当天题目固定，同一天重复打开不重新生成。
6. 被标记的题不再出现在每日题中。

**代码组织**

- 代码结构：`app/api/`（后端 Node）+ `app/web/`（前端 React），npm workspaces 单仓两包。
- AI 调用只在 `app/api/src/ai/` 一处，换服务商只改这里。
- 业务逻辑只在 `app/api/src/services/`，接口层不写逻辑。
- `data/` 与 `.env` 不进版本库，`data/` 要能整体复制搬走。
