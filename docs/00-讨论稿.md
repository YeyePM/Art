# 美术史复盘网站 · 讨论稿

> 状态：需求已收敛（v3，2026-10-07）
> 角色分工：AI = 产品（现在）→ 之后可能切换为前端 / 后端 / 设计
> 原则：**先把业务逻辑聊清楚，再写代码**。本文件随讨论持续更新。

---

## 一、这是什么东西

一个**个人向的网站**，用来做美术史知识的定期复盘，以及美感的持续训练。

---

## 二、要解决的问题

1. **知识不复盘就会遗忘**：中美史、外美史学过，但工作之后没有时间定期回看，脑子里的知识在流失。
2. **美感需要长期喂养**：作为美术专业出身的人，对"好看"的判断力和品味，需要持续、有质量的输入，而不是零散刷图。
3. **缺少固定的输入节奏**：现在的信息是碎的，没有"每天稳定来一点"的机制。

---

## 三、理想形态（用户原话整理）

- 每天推 **10 道题**：中国美术史、外国美术史
- 每天推 **1 张画**（"好看的话"）
- 留一些 **开放性问题**
- 一些 **书籍摘要 / 片段**，例如大卫·霍克尼《隐秘的知识》
- 整体要**专业**——用户本身是专业人士，不接受业余水平内容

---

## 四、关键判断

1. 这是**两件事**，机制不同，不能混为一谈：
   - **知识复盘**：可量化——题对不对、记没记住、有没有复习。
   - **美感训练**：难量化——看图、读画、形成品味，更偏"输入 + 主动输出"。
2. "每天推"背后真正的瓶颈是**内容供给**，不是界面。
3. **"AI 生成" 与 "要专业" 存在冲突**（已确认接受此风险）：
   - 实时生成的美术史硬事实（年代、作者归属、流派）会出错。
   - 已确认的应对：**先做实时生成，后续再加人工审核**。因此产品里需要预留一个**"标记问题"**的入口，把可疑内容攒起来，供以后集中审核。
4. "成体系"与"每天混着抽"不矛盾——**题库按体系建、每日抽取时打散**。
5. **"实时生成"依赖"落库"**（重要技术前提）：若题目每天实时生成、用完即弃，就不存在"题库"可打标签，也无从谈复习。
   因此实时生成的题必须**落库并打标签**，题库随使用累积——这是"成体系"和"错题复习"能成立的前提。

---

## 五、已确认的决策

### 第 1 轮（Go / No-Go 层）

| 议题 | 结论 |
| --- | --- |
| 内容来源 | **AI 生成 + 接公开资源**（画作走博物馆开放素材） |
| 使用范围 | **只给自己用**，不做多用户、不做账号体系 |
| 推送方式 | **打开网页就有**（每天首次打开生成/展示当日内容），不做主动提醒 |
| 复盘深度 | **全套**：错题复习 + 统计 + 连续打卡 + 笔记 |

### 第 2 轮（内容形态层）

| 议题 | 结论 |
| --- | --- |
| 题目形式 | **四种都要**：客观题 + 名词解释/简答 + 图像辨识题 + 开放论述题 |
| 题库组织 | **主题混合打散**（不按时间线推进） |
| 每天一张画 | **画 + 自己写一句**（输出式，不是纯输入） |
| 生成时机 | **先实时生成**，人工审核后置 |

### 第 3 轮（节奏与来源层）

| 议题 | 结论 |
| --- | --- |
| 每日负担 | **题目天天有**（每天 10 题）；**画 / 摘要 / 开放问题按周** |
| 题型配比 | **不固定，每天随机** |
| 书籍内容 | **直接放原文摘录**（个人自用、不公开传播，版权风险可接受） |

### 第 4 轮（秩序与范围层）

| 议题 | 结论 |
| --- | --- |
| 每周节奏 | **每周一批，随时可看**（不绑定具体哪一天） |
| 题型约束 | **随机但设上限**（论述 ≤ 1、名词 ≤ 2、图像辨识 ≤ 2） |
| 首版范围 | **一次做全套**（但按顺序建：内容引擎 → 今日页 → 复习 → 统计/笔记） |

### 第 5 轮（收尾层）

| 议题 | 结论 |
| --- | --- |
| 题库标签 | **细**：中外 × 时期 × 流派/门类 × 作者/作品/技法 |
| 复习算法 | **遗忘曲线**：1 / 3 / 7 / 15 天 |
| 一句话用途 | **存进画库，可回看**（形成审美档案） |
| 技术形态 | **前端 + 本机小后端**（数据存本机文件） |

---

## 六、遗留事项（不影响开工，建的过程中处理）

1. **AI 生成内容的把关入口**：预留"标记问题"，把可疑内容攒起来，供以后集中审核。
2. **图片来源接入**：确定大都会 / 芝加哥艺术馆 / 故宫的具体取图方式。
3. **题库初始生成策略**：首批生成多少题、覆盖哪些时期。

---

## 七、闭环（定稿）

**每日**
```
打开网站
  ↓
① 10 道题（题型随机）→ 逐题作答 → 即时反馈 + 解析
  ↓
完成打卡 → 错题进入复习队列
```

**每周**
```
② 1 张画 → 看 → 写一句话 → 存入笔记
③ 1 段书籍原文摘录 → 可收藏
④ 1 个开放问题 → 可选作答
```

---

## 八、页面结构（定稿）

| 页面 | 作用 |
| --- | --- |
| 今日 | 当日 10 题 + 本周的画 / 摘录 / 开放问题 + 完成状态 |
| 题库 / 练习 | 按标签自由刷题（超出每日配额的加练） |
| 画库 | 看过的画 + 自己写的话 |
| 笔记 / 收藏 | 攒下的片段与感想 |
| 统计 / 打卡 | 连续天数、正确率、题型分布、薄弱点 |
| 设置 | 内容偏好、每日配额、数据管理 |
