# 数据模型（SQLite 表设计）

> 来源：[../docs/02-技术方案.md](../docs/02-技术方案.md) 第五节 ｜ 定稿 2026-10-08
> 全部存在本机一个 SQLite 文件里（`data/` 目录）。
> **访问方式（2026-10-08 定）：`better-sqlite3` + 手写 SQL**，不上 ORM。所有 SQL 只在 `app/api/src/db/` 一处，业务层通过它读写。

---

## 硬约束

**字段要一次设计对**（尤其是标签、复习间隔、连对计数），否则 v0.2 迁移代价很大。
即使第一版不做的功能（如画库回看、笔记），只要表要建，字段就一并留好。

**`fragments` 表虽属 v0.2，也在 M0 与其它表一起建好**——避免以后改数据结构。

---

## 表清单

| 表 | 存什么 | 关键字段 |
| --- | --- | --- |
| `questions` | 题目库 | id、题型（客观/名词/图像辨识/论述）、题干、选项、答案、解析、**内容指纹**（去重用）、来源（AI/人工）、是否被标记问题 |
| `tags` | 标签 | id、名称、类别（中外 / 时期 / 流派 / 作者 / 作品 / 技法） |
| `question_tags` | 题目↔标签 | question_id、tag_id |
| `answers` | 作答记录 | id、question_id、日期、你的作答、是否正确、是否自评、用时 |
| `review_queue` | 复习队列 | question_id、**下次出现日**、**当前间隔（1/3/7/15）**、**连对计数**、状态（在队/出队） |
| `daily_sessions` | 每日任务 | 日期、当日 10 题的题目 id 列表、完成进度、是否打卡、**`hook`**（当天通知用的一句钩子） |
| `artworks` | 画作 | id、标题、作者、年代、流派、图片本地路径、来源库、外部 id |
| `artwork_notes` | 画库（你写的一句话） | artwork_id、日期、你写的内容、是否未写 |
| `excerpts` | 书籍摘录 | id、书名、章节、原文、你的收藏状态、周批次号 |
| `open_questions` | 开放问题 | id、题干、参考思路、你的作答（可选）、周批次号 |
| `weekly_batches` | 周批次 | 批次号、起止日期、画 id、摘录 id、开放问题 id |
| `notes` | 笔记 / 收藏 | id、类型、关联对象、内容、时间 |
| `checkins` | 打卡 | 日期、完成时间、当日题数 |
| `settings` | 设置 | 每日题量、题型上限、AI 配置、连续天数规则 |
| `flagged_items` | 标记问题 | 关联对象、标记时间、你的备注、处理状态 |
| `push_log` | **推送记录** | 日期、发送时间、文案、是否送达——防重复发 + 排查"今天怎么没弹" |
| `fragments` | **碎片池**（v0.2 内容入口） | id、类型（画 / 文字）、图片本地路径、你写的一句、AI 摘要、AI 标签、OCR 文字、识别状态、用在哪个周批次 / 哪道题 |

## 第一版建表范围（对照 MVP Spec 第 4 节）

| 表 | 第一版是否必建 |
| --- | --- |
| `questions` / `tags` / `question_tags` | 必建 |
| `answers` | 必建 |
| `review_queue` | 必建 |
| `daily_sessions` | 必建 |
| `checkins` | 必建 |
| `weekly_batches` | 必建 |
| `artworks` / `artwork_notes` | 必建 |
| `excerpts` / `open_questions` | 必建（只存只展示） |
| `flagged_items` | 必建 |
| `push_log` | 必建（推送进 MVP） |
| `fragments` | **建表，但第一版不用**（v0.2） |
| `notes` | **不建**，v0.2 再补 |
| `settings` | 不必建，第一版把参数写进配置文件即可 |

---

## `settings` 默认值

| 项 | 默认 |
| --- | --- |
| 每日题量 | 10 |
| 题型上限 | 论述 ≤ 1、名词解释 ≤ 2、图像辨识 ≤ 2 |
| AI 模型 | 智谱 `glm-5.3-flash` |
| 推送开关 | 开 |
| 推送时间 | **21:00** |
| 推送时间窗 | 09:00–22:00 |
| 跨天判定时区 | Asia/Shanghai |
